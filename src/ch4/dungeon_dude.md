# Dungeon Dud

Dungeon Dud has procedurally generated dungeons, monsters of increasing difficulty, and turn-based movement.

## Story

The hero's hometown has been overrun by monsters. The hero must navigate the dungeon, defeat monsters, and find the exit to save the town. Once they find the lost Amulet of Power, they can defeat the dungeon boss and save the town.

## Basic Game Loops

1. Enter dungeon level
2. Explore, revealing the map
3. Encounter monsters and fight or flee from them
4. Find items and power-ups
5. Find the exit to the next level - go to 1

## Minimum Viable Product (MVP)

1. Create a basic dungeon map
2. Place the player and let them walk around
3. Spawn monsters, draw them, and let the player kill them by walking into them
4. Add health and a combat system that uses it
5. Add healing potions
6. Display a "Game Over" screen when the player dies
7. Add the amulet and a dungeon boss that requires it to defeat

## Stretch Goals

1. Add fields of view
2. Add more interesting dungeon designs
3. Add some dungeon themes
4. Add multiple floors to the dungeon with the amulet and exit on the last floor
5. Add varied weapons to the game
6. Move to a data-driven design for spawning monsters
7. Consider visual effects
8. Consider sound effects
9. Consider keeping score
